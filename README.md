# 💊 Application Web de Gestion de Pharmacie

Projet académique de développement web (HTML, CSS, PHP, MySQL) pour la gestion d'une officine pharmaceutique.

## 🚀 Fonctionnalités principales
- **Gestion des stocks :** Suivi en temps réel des médicaments, dosages, prix et dates de péremption.
- **Alertes de stock :** Signalement des produits en rupture ou périmés.
- **Gestion des ventes :** Enregistrement des transactions.

## 🛠️ Technologies
- HTML5 / CSS3 / PHP / MySQL
